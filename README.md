# KIMHANI · 딜킬 LIVE

구글 시트나 서버 없이 실행되는 독립 점수판입니다. 분홍색 LIVE 패널, 4인 멤버, 60판 입력, 팀 목표, 멤버별 다이 차감, 딜 보너스, 치킨, 목표 달성 효과, 전체 화면, 데스크톱 크기 조절을 지원합니다.

## 사용

배포된 주소를 Chrome 또는 Edge에서 열고 입력하세요. 기록은 `localStorage`에 즉시 저장되어 같은 기기·같은 브라우저·같은 주소에서 새로고침 후 이어집니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 기기에서는 기록이 이어지지 않습니다. 서버로 경기 기록을 전송하지 않습니다. 여러 탭을 열면 같은 브라우저의 최신 기록을 반영합니다. 동시에 서로 다른 탭에서 입력하면 마지막 저장이 적용되므로 입력 탭은 하나를 권장합니다.

판을 선택하면 해당 판을 수정합니다. ‘저장하고 다음 판’은 다음 판으로 이동합니다. ‘목표 · 멤버’ 설정은 적용 버튼으로 저장하며 다이 기준 변경은 모든 판에 적용됩니다. 다이 기준 100은 1점 차감, 0은 차감 없음입니다. 소수 차감은 기존 시트처럼 팀에서는 소수점, 개인에서는 내림으로 계산합니다. 예: 기준 150 → 팀 -1.5점, 개인 -2점. 딜은 개인별 100당 1점, 남은 딜 합계 100당 1점이 보너스입니다. 사녹 치킨은 5점, 다른 맵은 8점입니다.

경기 기록 초기화는 목표와 멤버를 유지합니다. 목표 미달성 중인 기록 삭제는 확인 창을 띄웁니다. 목표 달성 시 초기화는 즉시 진행됩니다. 오른쪽 아래 브라우저 기본 손잡이로 점수판 크기를 조절할 수 있으며 모바일에서는 화면 폭에 맞춥니다.

## 빙고

상단 킬딜 / 빙고 탭으로 전환합니다. 빙고는 3×3, 4×4, 5×5, 100칸(10×10) 크기와 알파벳 / 숫자를 지원합니다. 작은 빙고의 알파벳은 A부터 채우며 Q는 Q/U로 표시합니다. 100빙고는 숫자 모드만 사용합니다. 숫자는 1부터 채웁니다. 각 크기·문자 조합의 글자와 체크는 킬딜 기록과 별도로 자동 저장됩니다.

칸을 클릭하거나 키보드 Enter/Space를 누르면 체크/취소합니다. 작은 보드는 빨간 색연필 X, 100칸은 배경색으로 표시합니다. 완성된 줄은 금색 테두리로 구분합니다. 가로·세로·양쪽 대각선의 완성 줄 수를 계산하며, 모든 칸을 체크하면 MISSION CLEAR가 크게 표시됩니다. ‘빙고판 계속 보기’로 효과를 닫고 진행할 수 있습니다.

‘글자 수정’에서 칸마다 최대 12자를 입력하고 ‘수정 완료’를 누릅니다. 빈칸은 이전 값으로 복원됩니다. ‘글자 섞기’는 수정한 글자를 유지한 채 순서를 섞고 체크를 지웁니다. ‘체크 초기화’는 현재 빙고판의 체크만 지웁니다. 진행 중 초기화·섞기에는 확인 창이 표시됩니다. 동작 줄이기 설정에서는 색연필·축하 애니메이션이 생략됩니다.

## 로컬 실행 및 검증

Node.js 18 이상에서 `npm start` 후 http://127.0.0.1:4173 접속. `npm test`로 점수 계산·저장 데이터 검증 테스트를 실행합니다. 별도 패키지 설치는 필요 없습니다. Google Fonts가 차단된 환경에서는 기기의 기본 한글 글꼴을 사용합니다.

## GitHub Pages

저장소 루트에 이 폴더의 파일을 올린 뒤 Settings → Pages → Build and deployment에서 **Deploy from a branch**, **main / (root)** 를 선택하세요. 빌드나 비밀 키 없이 배포됩니다. `.nojekyll` 파일을 유지하세요.

테스트와 로컬 서버는 개발 도구이며 배포 시 실행되지 않습니다. 서비스 데이터나 인증 정보는 코드에 포함하지 않습니다.
## 킬까기

상단 슬롯 단가 숫자는 직접 수정할 수 있습니다. 기본값은 100개이며 0~999999 범위의 정수를 입력하면 브라우저에 자동 저장합니다. Enter 또는 다른 곳 클릭으로 편집을 마치고 Esc로 편집 전 값으로 되돌립니다. 단가는 경기 기록 초기화와 별도로 유지됩니다.

목표는 000에서 시작합니다. 첫 슬롯 또는 현재값이 0이면 20~100을 대입하며, 이후에는 + / − / × / ÷와 20~100을 무작위로 뽑습니다. 나눗셈은 소수점 버림이고 BigInt로 큰 정수를 계산합니다. 목표가 음수가 되면 MISSION CLEAR, 0이면 계속 진행합니다.

슬롯은 버튼 자리에서 기호·십의 자리·일의 자리를 각각 약 0.75초에 결정합니다. 추첨 중 클릭 또는 Enter/Space로 즉시 결과를 공개하고, 최종 결과는 8초 유지하거나 클릭해서 닫습니다. 목표 값도 부드럽게 합산됩니다. 동작 줄이기 설정을 지원합니다.

킬 슬롯과 판수 룰렛은 매 추첨마다 각각 1% 확률로 고장납니다. 각각 ‘슬롯고장! 다음 기회에’, ‘룰렛 고장! 다음 기회에’를 표시하며 목표·멤버·판수·기록을 변경하지 않습니다. 고장 여부는 추첨 시작 때 한 번만 결정하므로 건너뛰기로 확률이 바뀌지 않습니다.

판 입력의 새 멤버 추가 / 판수 룰렛은 팝업 없이 목표 킬 카드 안에서 진행됩니다. 이름을 입력하고 뽑기를 누르면 0~5판 룰렛이 약 3.2초 회전하고 자동 등록됩니다. 같은 이름은 남은 판수가 누적되며 0판 일반 멤버는 경기 명단에 들어가지 않습니다. 고정참가는 멤버 설정에서만 바꿉니다.

활성 참가자는 고정참가를 포함해 최대 4명입니다. 초과 멤버는 등록 순서로 대기합니다. 대기 체크를 하면 경기 입력에서 빠지고 판수가 줄지 않습니다. 빈자리가 있을 때 체크를 풀면 즉시 합류하며, 4명이 꽉 찼다면 다른 참가자를 먼저 대기로 바꿉니다. 경기 저장으로 마지막 판 참가자가 종료되면 대기 순서대로 자동 합류하고 새 참가자의 판수는 다음 경기부터 차감합니다. 수동 대기는 체크를 풀거나 참가자가 종료되어 자동 합류하기 전까지 유지됩니다.

판 입력에는 활성 멤버가 자동으로 채워집니다. 이번 판에 함께하지 않은 사람은 ×로 제외합니다. 각자의 킬을 입력해 저장하면 팀 킬 합계가 목표에서 한 번 차감되고, 실제 참가한 일반 멤버만 1판 차감됩니다. 킬을 비우면 0킬 참가로 기록하며 한 판 합계는 최대 10,000킬입니다. 고정참가는 판수가 줄지 않으며 해제하면 남은 일반 판수를 적용합니다. 멤버 설정에서 남은 판수(0~999)를 직접 수정할 수 있습니다.

목표 숫자는 10만 단위에 맞춘 같은 글자 크기를 유지하며 자릿수에 따라 가로로 확장됩니다. 카드가 넓어져도 슬롯 버튼의 높이는 유지합니다. 화면 너비를 넘는 극단적으로 긴 숫자는 가로로 스크롤할 수 있습니다. 목표 숫자는 제목과 하단 버튼 사이에 배치하고, 슬롯 버튼은 정중앙에 고정하고 연한 막판 알림은 버튼 좌우에 나눠 표시합니다.

하단에는 완료·대기 멤버까지 함께한 판수·팀 킬·개인 킬을 보관합니다. 이전 공동 킬 기록은 개인 킬을 역산하지 않습니다. 판 초기화는 확인 후 목표·슬롯·경기·누적 킬을 비우고 이름·고정참가·현재 남은 판수·대기 상태를 유지합니다.

브라우저 로컬 저장소에 킬딜·빙고와 별도로 저장합니다. 다른 창의 변경을 반영하고, 손상된 저장 기록은 덮어쓰지 않습니다. 배포 파일에는 테스트용 데이터나 추첨 강제 결과가 포함되지 않습니다.
