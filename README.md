# KIMHANI · 딜킬 LIVE

구글 시트나 서버 없이 실행되는 독립 점수판입니다. 분홍색 LIVE 패널, 4인 멤버, 60판 입력, 팀 목표, 멤버별 다이 차감, 딜 보너스, 치킨, 목표 달성 효과, 전체 화면, 데스크톱 크기 조절을 지원합니다.

## 사용

배포된 주소를 Chrome 또는 Edge에서 열고 입력하세요. 기록은 `localStorage`에 즉시 저장되어 같은 기기·같은 브라우저·같은 주소에서 새로고침 후 이어집니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 기기에서는 기록이 이어지지 않습니다. 서버로 경기 기록을 전송하지 않습니다. 여러 탭을 열면 같은 브라우저의 최신 기록을 반영합니다. 동시에 서로 다른 탭에서 입력하면 마지막 저장이 적용되므로 입력 탭은 하나를 권장합니다.

판을 선택하면 해당 판을 수정합니다. ‘저장하고 다음 판’은 다음 판으로 이동합니다. ‘목표 · 멤버’ 설정은 적용 버튼으로 저장하며 다이 기준 변경은 모든 판에 적용됩니다. 다이 기준 100은 1점 차감, 0은 차감 없음입니다. 소수 차감은 기존 시트처럼 팀에서는 소수점, 개인에서는 내림으로 계산합니다. 예: 기준 150 → 팀 -1.5점, 개인 -2점. 딜은 개인별 100당 1점, 남은 딜 합계 100당 1점이 보너스입니다. 사녹 치킨은 5점, 다른 맵은 8점입니다.

경기 기록 초기화는 목표와 멤버를 유지합니다. 목표 미달성 중인 기록 삭제는 확인 창을 띄웁니다. 목표 달성 시 초기화는 즉시 진행됩니다. 오른쪽 아래 브라우저 기본 손잡이로 점수판 크기를 조절할 수 있으며 모바일에서는 화면 폭에 맞춥니다.

## 빙고

상단 킬딜 / 빙고 탭으로 전환합니다. 빙고는 3×3, 4×4, 5×5, 100칸(10×10) 크기와 알파벳 / 숫자를 지원합니다. 작은 빙고의 알파벳은 A부터 채우며 Q는 Q/U로 표시합니다. 100빙고는 숫자 모드만 사용합니다. 숫자는 1부터 채웁니다. 각 크기·문자 조합의 글자와 체크는 킬딜 기록과 별도로 자동 저장됩니다.

칸을 클릭하거나 키보드 Enter/Space를 누르면 체크/취소합니다. 작은 보드는 빨간 색연필 X, 100칸은 배경색으로 표시합니다. 완성된 줄은 금색 테두리로 구분합니다. 가로·세로·양쪽 대각선의 완성 줄 수를 계산하며, 모든 칸을 체크하면 MISSION CLEAR가 크게 표시됩니다. ‘빙고판 계속 보기’로 효과를 닫고 진행할 수 있습니다.

‘글자 수정’에서 칸마다 최대 12자를 입력하고 ‘수정 완료’를 누릅니다. 빈칸은 이전 값으로 복원됩니다. ‘글자 섞기’는 수정한 글자를 유지한 채 순서를 섞고 체크를 지웁니다. ‘체크 초기화’는 현재 빙고판의 체크만 지웁니다. 진행 중 초기화·섞기에는 확인 창이 표시됩니다. 동작 줄이기 설정에서는 색연필·축하 애니메이션이 생략됩니다.

## 로컬 실행 및 검증

Node.js 18 이상에서 `npm start` 후 http://127.0.0.1:4173 접속. `npm test`로 점수 계산·저장 데이터 검증 테스트를 실행합니다. 별도 패키지 설치는 필요 없습니다. Google Fonts가 차단된 환경에서는 기기의 기본 한글 글꼴을 사용합니다.

## GitHub Pages

저장소 루트에 이 폴더의 파일을 올린 뒤 Settings → Pages → Build and deployment에서 **Deploy from a branch**, **main / (root)** 를 선택하세요. 빌드나 비밀 키 없이 배포됩니다. `.nojekyll` 파일을 유지하세요.

테스트와 로컬 서버는 개발 도구이며 배포 시 실행되지 않습니다. 서비스 데이터나 인증 정보는 코드에 포함하지 않습니다.
## 킬까기

킬까기는 000에서 시작합니다. ‘킬 슬롯 돌리기’는 최초·현재값 0일 때 20~100을 대입하고, 그 외에는 + / − / × / ÷와 20~100을 각각 무작위로 선택합니다. 기호 → 십의 자리 → 일의 자리 순서로 멈춥니다. 100은 백의 자리에 1을 함께 표시합니다. 나눗셈은 소수점 버림이며 큰 정수도 정확히 계산합니다. 현재 킬이 음수가 되면 종료되고 0은 계속 진행합니다.

이름과 고정참가 여부를 입력해 ‘판수 뽑아 추가’를 누르면 0~5판이 추가됩니다. 같은 이름에는 누적되며, 0판은 실제 추가 없이 결과를 보여줍니다. 일반 참가자는 ‘킬 입력 → 경기 저장’ 때마다 1판씩 줄어듭니다. 1판이 남으면 왼쪽에 막판 알림이 나타나고 0판이면 활성 명단에서 빠집니다. 고정참가자는 판수 제한 없이 계속 참가하고 고정을 해제하면 기존 남은 판수가 적용됩니다.

경기 저장은 입력한 킬을 목표에서 차감하고 현재 참가자 전원에게 해당 경기의 함께한 킬을 기록합니다. 0킬 경기에도 판수는 차감됩니다. 하단에는 종료된 참가자를 포함해 이름별 함께한 판수·킬이 누적되며 미션 완료 후에도 확인할 수 있습니다. 참가자별 기록은 함께 플레이한 팀 킬 합계이므로 참가자들의 킬을 더하면 전체 킬과 같지 않을 수 있습니다.

‘마지막 입력 취소’는 가장 최근의 슬롯, 참가자 추가/고정 변경, 경기 저장을 되돌리며 참가 명단과 누적 기록도 같이 복원합니다. ‘새 킬까기’는 확인 후 현재 미션의 모든 기록을 초기화합니다. 슬롯 중에는 중복 입력을 막으며 새로고침 시 완료된 기록을 복원합니다. 진행 중 슬롯은 저장되지 않습니다. 저장은 기존 킬딜·빙고와 별도이며 브라우저 로컬 저장소를 사용합니다.
### 참가자별 경기 입력과 슬롯 연출

목표 아래의 ‘킬 슬롯 돌리기’ 버튼을 누르면 같은 자리에서 슬롯이 나타나 추첨합니다. 결과가 목표에 반영된 뒤 버튼이 돌아옵니다. 사칙연산은 흐림 없이 진한 바탕에 표시하고 각 기호·숫자가 멈출 때 테두리와 착지 효과를 줍니다. 목표 숫자는 최종값까지 부드럽게 올라가거나 내려가며, 동작 줄이기 설정에서는 즉시 반영합니다.

슬롯 아래 ‘이번 판 함께한 킬’에서 현재 참가자가 자동으로 채워집니다. 이름을 직접 추가할 수 있고 이번 판에 참여하지 않은 사람은 ×로 제외합니다. 각자의 킬을 입력해 한 번 저장하면 합계가 목표에서 차감되고, 해당 명단의 일반 참가자만 1판 차감됩니다. 이름을 넣고 킬을 비우면 0킬 참가로 기록합니다. 중복 이름과 합계 10,000킬 초과는 저장하지 않습니다.

하단의 ‘함께한 킬’은 해당 사람이 함께한 경기의 팀 킬 합계이고, ‘개인 킬’은 새 입력 방식으로 기록한 본인의 킬 합계입니다. 기존 단일 합계 입력 기록은 유지하며 개인 킬을 역산하지 않고 —로 표시합니다.

오른쪽의 판 입력 / 멤버 설정 탭에서 한 판씩 입력합니다. 멤버 설정은 이름, 남은 판수(0~999), 고정참가를 직접 저장하거나 후원 판수(0~5)를 추가할 수 있습니다. 같은 이름으로 저장하면 누적 킬은 보존하고 남은 판수·고정참가만 바꿉니다. 판 입력의 저장하고 다음 판 버튼은 다음 판 번호와 활성 참가자 명단을 자동으로 준비합니다.

슬롯은 버튼 자리에 나타나 약 8초(기호 2.8초, 십의 자리 2.3초, 일의 자리 2.9초) 추첨합니다. 추첨 중 슬롯을 클릭하거나 Enter/Space를 누르면 즉시 결과를 공개합니다. 추첨 안내 문구와 계산식은 표시하지 않습니다.

### 새 멤버 룰렛

판 입력의 새 멤버 추가에서 이름과 고정참가 여부를 입력하고 뽑기를 누릅니다. 0~5판 원형 룰렛이 약 3.2초 회전한 뒤 해당 이름을 멤버 설정에 자동 등록합니다. 같은 이름은 기존 남은 판수에 추첨 결과를 더합니다. 0판도 멤버 설정에 남으며 일반 참가자의 경기 명단에는 양수 판수인 멤버만 들어갑니다. 고정참가는 0판이어도 참가합니다. 추첨 중 중복 제출·닫기를 막고 완료된 결과만 저장합니다.

판 번호, 마지막 입력 취소, 새 킬까기 버튼 및 판 차감·종료 조건 안내 문구는 화면에서 제거했습니다. 과거 판 번호는 하단 경기 기록에만 남습니다.
